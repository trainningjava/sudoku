# 🧩 Sudoku

Projeto desenvolvido em Java para resolução de jogos Sudoku.

## 🎓 Formação e Contexto do Projeto

Este repositório foi desenvolvido durante minha participação no bootcamp Almaviva Solutions - Back-end com Java & QA, promovido pela DIO (Digital Innovation One).

## 📋 Sobre o Projeto

Este projeto implementa a lógica necessária para resolver desafios de Sudoku utilizando algoritmos de validação e preenchimento do tabuleiro.

O objetivo é praticar:

* Programação Orientada a Objetos
* Estruturas de Dados
* Algoritmos de Busca
* Backtracking
* Boas práticas de desenvolvimento Java

## 🧠 Regras do Sudoku

O Sudoku é composto por uma grade 9x9.

As regras são:

* Cada linha deve conter números de 1 a 9.
* Cada coluna deve conter números de 1 a 9.
* Cada região 3x3 deve conter números de 1 a 9.
* Não podem existir números repetidos.

## ⚙️ Como Executar

### Clonar o projeto

```bash
git clone https://github.com/trainningjava/sudoku.git
```

### Entrar no diretório

```bash
cd sudoku
```

### Executar

```bash
mvn clean install
mvn exec:java
```

## ✅ Testes

Para executar os testes:

```bash
mvn test
```
